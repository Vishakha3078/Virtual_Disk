## Overview

This project implements basic file management operations on a virtual
disk using C. It provides functionality for creating, adding, retrieving,
and deleting files, along with encoding and decoding operations for
stored data.

A C-based implementation of a virtual disk and file management system.

## Features

- Create and manage files on a virtual disk
- Add and retrieve files
- Delete files
- Encode and decode stored data
- Text file handling and manipulation
- Implementation of core virtual disk operations
